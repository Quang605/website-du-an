# Dự án DIY — Trang giới thiệu

Trang giới thiệu dự án DIY/điện tử, viết bằng HTML, CSS và JavaScript thuần. Không cần cài package hoặc build.

## Xem trang

- Mở `index.html` trực tiếp trong trình duyệt; hoặc
- Chạy máy chủ tĩnh trong thư mục dự án: `python -m http.server 8000`, sau đó mở `http://localhost:8000`.

## Nội dung cần thay

- Tên dự án, mô tả và liên kết trong `index.html` (bao gồm `DỰ ÁN DIY`, tiêu đề, phần giới thiệu và liên hệ).
- Danh sách linh kiện và các bước hướng dẫn trong `index.html`.
- Ba khung hình minh họa trong thư viện hiện được vẽ bằng CSS tại `styles.css`; thay bằng hình ảnh do bạn sở hữu hoặc được phép sử dụng.
- Email `hello@example.com` và các thông tin liên hệ mẫu.
- Màu sắc, kiểu chữ và bố cục responsive trong `styles.css`.

Các hình minh họa hiện tại chỉ là đồ họa CSS tự tạo. Trang không tải tài nguyên bên ngoài, không cài đặt firmware, không điều khiển hoặc ghi dữ liệu lên thiết bị.
